Place your pet GIFs here using the filenames below (or update `PetView.gif_paths` to match your filenames):

- `happy.gif`
- `sad.gif`
- `neutral.gif`
- `super_tired.gif`
- `super_full.gif`

Action GIF filenames (place your action animations here):
- `feed.gif`     (shown while feeding)
- `rest.gif`     (shown while resting/sleeping)
- `play.gif`     (shown while playing)

Notes:
- Animated GIFs are supported. If you want to use PNG/JPG, install Pillow in your venv (`pip install pillow`) and update `PetView.gif_paths` accordingly.
- Example: `assets/happy.gif` will be shown when the pet is happy.
